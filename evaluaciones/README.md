## Requisitos Generales de Entrega

Cada subcarpeta de evaluación debe contener exactamente lo necesario para:
1. **Construir y empaquetar** el código fuente.
2. **Configurar y desplegar** los componentes e infraestructura.
3. **Revisar y validar** los requerimientos mediante el `README.md` específico de la entrega.
4. **Proteger secretos:** Ninguna credencial ni token real debe estar presente en el código versionado.
