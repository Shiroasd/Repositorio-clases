# DevLog Personal · DSY1107

El **DevLog** es el registro semanal individual de tu evolución técnica, aprendizajes y resolución de bloqueos durante el semestre.

> **Regla de oro:** Las semanas no organizan carpetas de código ni laboratorios; **únicamente el DevLog utiliza semanas porque registra el proceso en el tiempo.**

---

## Formato Oficial

Cada entrada debe cumplir la siguiente estructura:

```markdown
# DevLog · Semana XX

## Objetivo
...

## Avance
...

## Bloqueo
...

## Aprendizaje
...

## Siguiente
...
```

Manual detallado: [Guía del DevLog](../DEVLOG-ESTUDIANTE.md)
